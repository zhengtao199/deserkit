🆕 新增功能（在「利用中心」页签）

① 全类型自动识别 + 半自动串联 （自动编排）
全自动、安全非破坏地探测 SpringBoot / Shiro / Fastjson / XStream 四类漏洞；利用阶段需显式 confirm=1 才会开火，每个漏洞是独立「执行/确认」动作，绝不自动开火。
② 反弹 Shell 通道文件传输 （Shell 通道）
经已建立的反弹 shell 上传 / 下载文件：优先 curl/wget + 临时 HTTP 服务加速，失败回退 shell 通道 base64 分块。
③ 一句话木马自动落地 （Shell 通道）
拿到 shell 后向目标 web 根写入 PHP/JSP/ASP 一句话木马（密码 / base64·xor·plain 加密可配），并回显候选可访问 URL。仅落地不执行。
打开利用中心 → 进入后选「自动编排 / Shell 通道」分组即可看到新控件。
